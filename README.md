# 펫플스

동네에서 반려견 산책 친구를 찾는 웹 프로토타입입니다. 매칭 카드에서 반려견과 보호자 프로필을 살펴보고, 채팅과 커뮤니티 화면을 둘러볼 수 있습니다.

[매칭 카드 화면 미리보기](apps_screen.png)

## 로컬에서 둘러보기

저장소 폴더에서 정적 파일 서버를 실행합니다. Python이 설치되어 있다면 다음 명령을 쓸 수 있습니다.

```sh
python -m http.server 8000 --bind 127.0.0.1
```

브라우저에서 [펫플스 첫 화면](http://127.0.0.1:8000/)을 엽니다. 데모에서 만든 프로필은 해당 브라우저의 로컬 저장소에 보관됩니다.
